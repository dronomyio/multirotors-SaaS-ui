Build a Headless Next.js (App Router) storefront and a Node.js/TypeScript Mastra AI backend that integrates with a Shopify store. The primary feature is an immersive AI chat interface designed to handle complex component composition and programmatic order insertion.

CRITICAL PAYMENT & ORDER SAFETY RULES:
1. Base item pricing and live storefront catalogs must be read natively via the Shopify Storefront API. Do not hardcode prices or manipulate the existing backend order book manually.
2. If a customer decides to buy an AI-generated bundle or composition, the system must programmatically use the Shopify Admin REST/GraphQL API to generate a temporary Draft Order or add items to an updated cart line, pushing the user securely to the official Shopify Checkout page for true payment processing. The payment and final order fulfillment must remain within Shopify's secure rail.

FRONTEND CHAT INTERFACE REQUIREMENTS:
1. Provide an expansive chat screen (collapsible sidebar or full-view dashboard) matching the branding of 'https://multirotors.store'.
2. The user can type unstructured complex inputs (e.g., "I want an FPV drone with Orqa goggles").
3. The UI must dynamically render a specialized "Composition Layout" when the AI responds, itemizing found vs sourced items, calculated taxes, real-time shipping costs, estimated delivery windows, and an interactive structural invoice summary.

BACKEND MASTRA AI IMPLEMENTATION:
1. Initialize a Mastra Agent (`@mastra/core/agent`) using TypeScript.
2. Implement Core Agent Tools using Mastra's tool system:
   - `searchShopifyCatalog`: Searches your live Shopify store for requested items (e.g., FPV drones, cameras, LIDAR).
   - `searchExternalWeb (Tavily/Similar)`: If an item like "Orqa goggles" is unavailable or out of stock locally, the agent triggers this tool to look up actual external product listings, pulling real market prices.
   - `calculateQuoteMetadata`: Takes the array of local + external components, computes a standardized local sales tax (or uses a tax estimation API), and queries real-world courier estimates for shipping costs and delivery duration.
   - `generateProFormaInvoice`: Automatically compiles all structured item lines into an invoice data object with specific fields: Item Name, Price, Tax, Shipping Cost, Total Cost, and Estimated Shipping Time.
   - `createShopifyLineAndDraftOrder`: If the user explicitly signals an intent to purchase (e.g., clicks "Accept Invoice & Buy Now"), this tool uses the Shopify Admin API to programmatically insert the external sourced components as custom ad-hoc line items on a new Shopify Draft Order, aggregates them with the local store products, and outputs a secure payment link generated by Shopify.

DEVELOPMENT ARCHITECTURE:
- Build complete validation schemas using Zod for all internal tools and APIs.
- Provide a clear setup structure in a `.env.template` file detailing keys for OPENAI_API_KEY, TAVILY_API_KEY, SHOPIFY_STORE_DOMAIN, and SHOPIFY_ADMIN_API_ACCESS_TOKEN.
